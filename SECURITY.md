# Безопасность DocPerfect

Если нашли уязвимость, **не публикуйте её детали и личные данные в открытых Issues**. Свяжитесь с владельцем GitHub-аккаунта `hothuman` приватным каналом, указанным в профиле. До подтверждения исправления не размещайте эксплойт публично.

DocPerfect обрабатывает DOCX локально, но подключённый внешний MCP-клиент может передавать извлечённые фрагменты своему ИИ-провайдеру. Предоставляйте агенту минимальные права: `DOCPERFECT_AGENT_WRITES=0` и ограниченный `DOCPERFECT_ALLOWED_ROOTS`.

# Безопасность DocPerfect

**Локальный desktop.** Приложение не требует входа в аккаунт и не отправляет текст DOCX по сети. MCP работает через stdio; программа не открывает HTTP-порт. Но подключённый сторонний агент может передавать содержимое документов облачной модели.

**Чтение:** вход ограничен DOCX как ZIP (50 МБ сжатый, 250 МБ суммарно разжатый, 2000 частей и дополнительные предохранители). Это не полноценный sandbox; не открывай подозрительные документы на привилегированном компьютере.

**Права агента:** `DOCPERFECT_ALLOWED_ROOTS` задаёт разрешённые папки; `DOCPERFECT_AGENT_WRITES=0` по умолчанию запрещает операции записи в MCP. Включение записи в конфигурации — осознанное решение; одно включение позволяет многократные операции без отдельного GUI-подтверждения. Права Windows процесса всё равно действуют.

**Новый файл:** `save_new` и адресные операции не перезаписывают исходный DOCX; если путь вывода уже существует, следует отказ. Адресные замены используют SHA-256 источника и проверку структуры абзаца. Для сложных OOXML-объектов замена может быть запрещена.

**Журнал:** сохраняет пути, действия и статусы, но не текст документа. Папки и пути могут содержать конфиденциальные названия. Пользователь управляет файлами истории локально через папку данных.

**Сборка:** не доверяй неподписанному EXE из неизвестного источника; пользуйся сборкой из проверенных исходников. Программа пока не подписана сертификатом издателя.

# Поддержка DocPerfect

Для сообщений об ошибках используйте [GitHub Issues](https://github.com/hothuman/DocPerfect/issues). Укажите ОС и версию, шаги воспроизведения, ожидаемый и фактический результат. **Не прикладывайте настоящие документы с личными сведениями**.

Для загрузки приложения откройте [Releases](https://github.com/hothuman/DocPerfect/releases). Если релиза ещё нет, дождитесь официальной публикации: исходники не распространяются через публичный репозиторий.

# DocPerfect 1.0.0 — Windows и Ubuntu

Первый публичный выпуск DocPerfect: русскоязычное приложение для создания, проверки и исправления документов Microsoft Word (.docx) и инструменты для внешних ИИ-агентов.

## Что нового

- Минималистичный интерфейс **Clean Workspace Red**, светлая и тёмная темы, фирменный логотип и отключаемая анимация запуска.
- Создание DOCX из текста, Markdown и JSON; проверка и исправление поддерживаемых правил оформления с сохранением исправленной копии.
- Профили и образцы оформления, работа с несколькими документами, история операций.
- **MCP stdio** и JSON CLI для ИИ-агентов: чтение больших DOCX небольшими фрагментами, структура, поиск, таблицы, проверки и адресные правки с разрешением на запись.
- Windows 10/11 x64: установщик и portable ZIP; Ubuntu 22.04/24.04 x86_64: `.deb` и portable `.tar.gz`.

Конечным пользователям Python не требуется. Ubuntu-сборка предназначена для `amd64`, не ARM.

## Приватность и ограничения

Обработка DOCX выполняется локально. Внешний облачный ИИ-агент может отправлять извлечённый текст своему провайдеру. MCP-запись выключена по умолчанию, доступ к папкам можно ограничить. Текст Word показывается структурно; сноски, колонтитулы, рисунки и сложные OOXML-структуры покрываются не полностью. Используйте проверку итогового DOCX в офисном редакторе для важных документов. Windows EXE не подписан сертификатом издателя.

Публикация **не происходит автоматически по тегу**: требуется успешный CI и отдельный ручной допуск после проверки прав и лицензий Qt.

# DocPerfect

**Документы Word — проще. Для людей и ИИ-агентов.**

[Windows 10/11](#установка-на-windows) · [Ubuntu 22.04 / 24.04](#установка-на-ubuntu) · [Интеграция с ии](#для-ии-агентов) · [Ограничения](#что-важно-знать)

</div>

DocPerfect — локальное настольное приложение для создания, проверки и аккуратного исправления `.docx`. В нём есть понятный русскоязычный интерфейс и отдельные инструменты для внешних ИИ-агентов через **MCP** и **JSON CLI**. Работать с документами можно без регистрации, подписки и обязательного интернет-соединения.

**Статус:** страница загрузки DocPerfect. Дистрибутивы появятся в [Releases](https://github.com/hothuman/DocPerfect/releases) после тестов Windows и Ubuntu и завершения проверки лицензий. Пока релизных файлов нет, приложение нельзя считать опубликованным.

## Что умеет

| Для обычных пользователей | Для ИИ-агентов |
|---|---|
| Создание DOCX из текста, Markdown или JSON | MCP-сервер через stdio без HTTP-сервера |
| Проверка отступов, шрифтов и других поддерживаемых правил | Получение структуры и заголовков |
| Исправление оформления **в отдельной копии** | Чтение выбранных разделов и абзацев небольшими фрагментами |
| Использование профилей и образцов оформления | Поиск текста и чтение таблиц |
| Обработка нескольких DOCX за один запуск | Проверка, создание и адресное изменение документов по разрешению |
| История действий, светлая/тёмная темы и анимация запуска | Ограничение доступа к папкам; запись **выключена** по умолчанию |

### Три шага для работы

**1. Откройте DOCX** → **2. Выберите проверку** → **3. Просмотрите и сохраните исправленную копию**. Оригинал не перезаписывается.

## Установка на Windows

**Windows 10/11 x64.** На странице [Releases](https://github.com/hothuman/DocPerfect/releases/latest) будут доступны:

- `DocPerfect_Setup_1.0.0_Windows_x64.exe` — обычная установка с ярлыком и меню «Пуск».
- `DocPerfect_1.0.0_Windows_x64_Portable.zip` — распаковать и запустить `DocPerfect.exe`.

В том же комплекте доступны `DocPerfect-CLI.exe` и `DocPerfect-MCP.exe`. **Пользователю не нужен Python**. Установщик пока не подписан цифровой подписью; Windows SmartScreen может показать предупреждение.

## Установка на Ubuntu

**Ubuntu 22.04/24.04, x86_64 (amd64).** Релиз будет содержать:

- `docperfect_1.0.0_amd64.deb` — системная установка;
- `DocPerfect_1.0.0_Ubuntu_amd64_Portable.tar.gz` — без установки.

**Установка `.deb`** после скачивания:

```bash
sudo apt install ./docperfect_1.0.0_amd64.deb
docperfect
```

После этого приложение появится в меню. Консольная версия — `docperfect-cli`, MCP-сервер — `docperfect-mcp`.

**Portable**:

```bash
mkdir -p ~/Applications
tar -xzf DocPerfect_1.0.0_Ubuntu_amd64_Portable.tar.gz -C ~/Applications
~/Applications/DocPerfect/DocPerfect
```

Для приложения из релиза не требуется отдельно ставить Python. На конкретных конфигурациях Ubuntu могут потребоваться системные библиотеки Qt/X11; `.deb` перечисляет основные зависимости. [Подробная инструкция и проверка Ubuntu](docs/RELEASE_UBUNTU.md).

## Для ИИ-агентов

DocPerfect **не содержит собственную нейросеть**. Он подключается к внешнему MCP-клиенту и выступает инструментом работы с DOCX. Это позволяет не отправлять весь большой документ в один запрос: агент сначала получает оглавление, затем нужный фрагмент.

**MCP на Ubuntu (пример настройки):**

```json
{
  "mcpServers": {
    "docperfect": {
      "command": "/usr/bin/docperfect-mcp",
      "args": [],
      "env": {
        "DOCPERFECT_ALLOWED_ROOTS": "/home/USER/Documents",
        "DOCPERFECT_AGENT_WRITES": "0"
      }
    }
  }
}
```

Замените `USER` и путь на собственные. Для portable-сборки укажите **абсолютный путь** к `DocPerfect-MCP` внутри распакованного архива. На Windows используйте путь к `DocPerfect-MCP.exe`, расположенный рядом с главным приложением. Формат конфигурации зависит от MCP-клиента.

**CLI-пример на Ubuntu:**

```bash
docperfect-cli agent info ~/Documents/example.docx
docperfect-cli agent outline ~/Documents/example.docx
docperfect-cli agent read ~/Documents/example.docx --limit 10 --max-chars 3000
docperfect-cli agent search ~/Documents/example.docx "договор"
```

Запись отключена по умолчанию (`DOCPERFECT_AGENT_WRITES=0`). При разрешении изменения выполняются в **новый файл**; для адресной замены предусмотрен предварительный план и контрольная сумма. Не давайте доступ к папкам с секретами. Внешний **облачный агент** может передавать извлечённый текст своему провайдеру — настройки приватности такого клиента остаются за ним.

## Что важно знать

- DocPerfect работает с `.docx` и **не открывает старый `.doc`**.
- Предпросмотр документа структурный, а не полностью точная визуализация страниц Microsoft Word.
- Сноски, колонтитулы, картинки, фигуры, сложная нумерация и некоторые OOXML-структуры могут обрабатываться неполно; после серьёзных правок проверяйте результат в Word или ONLYOFFICE.
- Чтение большого DOCX может использовать временный SQLite-индекс, но это не означает полноценное потоковое редактирование всех объектов Word.
- Исходный код DocPerfect **проприетарный** и не содержится в публичном репозитории — см. [`LICENSE`](LICENSE). Права на Qt и другие сторонние компоненты сохраняются; до публикации **необходимо завершить проверку LGPL/GPL и подготовить необходимые лицензионные материалы и исходники Qt**.

Скачивайте только файлы из [официальных Releases](https://github.com/hothuman/DocPerfect/releases). Сверяйте SHA-256 с `SHA256SUMS.txt` из того же релиза. Бинарники собираются из приватного репозитория в GitHub Actions, проходят автоматические проверки Windows и Ubuntu и публикуются только после отдельного разрешения правообладателя и проверки сторонних лицензий.

Не размещайте в Issue документы с личными данными. Об ошибке можно сообщить через раздел [Issues](https://github.com/hothuman/DocPerfect/issues), приложив обезличенные шаги воспроизведения. О раскрытии уязвимостей см. [Security](SECURITY.md).
